Workshop

Make local texture-pack manifests, write JavaScript mod drafts, and manage your schematics.

Texture packs Mods (code) Schematics

Texture packs

Choose image files to bundle into a portable, local BloxdBuilder pack manifest.

Images are read in your browser and included in the downloaded JSON manifest. This creates a local pack file; it does not install textures into Bloxd.

Select at least one image to build a manifest.

Mods (code)

Write and keep a JavaScript mod draft in this browser, or download it as a .js file.

Drafts are saved in this browser.

Code is saved and downloaded, not executed by this page. Review a mod before using it in any game or tool.

Schematics

Export a Bloxd schematic as a .bloxdschem file, or import a schematic created by this builder.

Worlds stay in this browser unless you export them.
